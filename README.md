# kyul_web — 「결」 공식 랜딩페이지

한글 단어 퍼즐 「결」을 소개하는 스크롤 인터랙티브 랜딩페이지. — https://kyul.chartq.app

- **컨셉**: 세로 스크롤이 수묵 두루마리(橫卷)를 펼친다 — 불→물→빛→돌→숨→결, 창세의 여정을 캔버스 산수화로 스크럽
- **디자인**: 게임 정본과 동일한 이색 체계 — 한지(#e7e2d6) + 먹(#20201c) + 낙관 주홍(#9a3324), 나눔명조
- **인터랙션**: 스크롤-스크럽 캔버스 여정 · 플레이 가능한 미니 퍼즐 데모(물·불) · 먹 번짐 호버/클릭 파문 · 히어로 패럴랙스
- **스택**: 순수 HTML/CSS/JS, 의존성 0 (폰트만 Google Fonts)

## 로컬 실행
```bash
python3 -m http.server 8899
# http://localhost:8899
```

## 구조
- `index.html` — 전체 마크업
- `css/style.css` — 수묵 디자인 시스템
- `js/main.js` — 두루마리 캔버스 스크럽 엔진 + 미니 데모
